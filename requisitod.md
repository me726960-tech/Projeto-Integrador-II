## Requisitos Funcionais 
Os requisitos funcionais descrevem o que o sistema deve fazer em termos de recursos e interações do usuário.

| Código | Descrição |
| :--- | :--- |
| **RF-01** | O sistema deve permitir o envio de alertas rápidos da sala de aula para a diretoria, coordenação e secretaria. |
| **RF-02** | O sistema deve possuir um botão para solicitação de presença/subida de professor para a sala de aula. |
| **RF-03** | O sistema deve permitir a emissão de chamados de emergência ou suporte operacional (ex: manutenção, limpeza, médica). |
| **RF-04** | O painel administrativo da diretoria deve receber e exibir as notificações com a identificação exata da sala solicitante. |
| **RF-05** | O aplicativo deve permitir o envio de recados e avisos gerais da diretoria para os terminais das salas de aula. |
| **RF-06** | O sistema deve manter um histórico com data, hora e status (pendente/atendido) de todas as solicitações enviadas. |

## Requisitos Não Funcionais
Os requisitos não funcionais definem os critérios de qualidade, desempenho e restrições técnicas do projeto.

| Código | Descrição |
| :--- | :--- |
| **RNF-01** | **Desempenho & Leveza:** O aplicativo e o sistema operacional devem ser extremamente leves para rodar com fluidez em hardware antigo (mínimo de 1GB de RAM). |
| **RNF-02** | **Modo Kiosk (Bloqueio):** O dispositivo deve ser travado para rodar exclusivamente o aplicativo de comunicação, impedindo o acesso a configurações do sistema ou navegação externa. |
| **RNF-03** | **Usabilidade:** A interface do aplicativo deve ter botões grandes, intuitivos e de fácil toque para agilizar o uso em sala de aula. |
| **RNF-04** | **Conectividade:** O sistema deve funcionar sob a rede Wi-Fi local da escola, minimizando o consumo de dados e dependência de internet externa. |
| **RNF-05** | **Disponibilidade:** O aplicativo deve inicializar automaticamente assim que o celular for ligado ou reiniciado. |
| **RNF-06** | **Segurança:** A comunicação entre os terminais e o servidor central da escola deve ser criptografada para evitar envios falsos de alertas. |
